# FORMA — premium portfolio

A dark, responsive portfolio for a freelance web developer in Bishkek. Built with React, Vite, Tailwind CSS v4, and Lucide for interface icons. Social icons are custom inline SVGs.

## Run locally

```bash
npm install
npm run dev
```

Replace the placeholder WhatsApp number, Telegram username, and social links in `src/main.jsx` before launch.
